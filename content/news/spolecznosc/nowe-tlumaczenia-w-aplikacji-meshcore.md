# Nowe tłumaczenia w oficjalnej aplikacji MeshCore
8 lipca 2026, o godzinie 10:26, do oficjalnej aplikacji MeshCore trafiły nowe ciągi znaków w interfejsie. Przetłumaczyliśmy je już na język polski. 🙂

## Lista zmian

| Angielski                        | Polski                                   |
|----------------------------------|------------------------------------------|
| You don't have any channels.     | Nie masz żadnych kanałów.                |
| Region Scope                     | Zakres regionu                           |
| Catalan                          | Kataloński                               |
| Select Channel                   | Wybierz kanał                            |
| You shared this channel          | Udostępniłeś ten kanał                   |
| Some nodes are missing position  | Niektórym węzłom brakuje pozycji         |
| Self position is unknown         | Twoja pozycja jest nieznana              |
| Sender position is unknown       | Pozycja nadawcy jest nieznana            |
| {x}-byte paths can be inaccurate | Ścieżki {X}-bajtowe mogą być niedokładne |
| Show Advanced Settings           | Pokaż ustawienia zaawansowane            |
| Hide Advanced Settings           | Ukryj ustawienia zaawansowane            |
| Request Name                     | Nazwa żądania                            |

> [!NOTE]
> Tłumaczenie trafi do wszystkich użytkowników wraz z kolejną aktualizacją oficjalnej aplikacji MeshCore.
